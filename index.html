How it works

Four clean layers.
No tangled mess.

Every layer has exactly one job. The render backend is swappable — plug in Vulkan, DX12, or WebGPU without touching anything else.

Dirty Tracking
Only changed regions of the scene graph are re-evaluated. Static sub-trees are cached and skipped entirely.
Batch Renderer
UI elements collected by material and depth before GPU submission. Eliminates redundant state changes — 68% fewer draw calls.
Zero-cost Layout
Layout engine operates in a single forward pass for most cases. No layout thrashing, no forced reflows.
Render Backends

Metal removed.
Everything else added.

Metal is proprietary, requires Apple developer program enrollment, and goes against Framm's open-source philosophy. We replaced it with 5 fully open backends.

Cross-Platform
OpenGL
OpenGL 3.3+ — widest compatibility. Linux, Windows, Android, macOS. The default fallback backend.
Stable · Default
Linux · Windows · Android
Vulkan
Low-overhead, explicit GPU control. Best for high-performance applications with complex scenes and 1000+ nodes.
Beta
Windows
DirectX 11
DirectX 11 for Windows legacy support. Broad hardware compatibility, excellent driver stability on older GPUs.
Beta
Windows (Modern)
DirectX 12
DirectX 12 for modern Windows. Explicit command lists, descriptor heaps, parallel workloads — maximum throughput.
Planned
Browser · Future Native
WebGPU
Run Framm in the browser via Emscripten. WebGPU is also positioned as the future cross-platform GPU standard.
Planned
Embedded · CI · Testing
Software
CPU-only rasterizer. No GPU required — perfect for embedded devices, headless CI snapshot testing, and fallback environments.
Stable
METAL REMOVED
Apple Metal requires enrollment in the Apple Developer Program, proprietary SDK agreements, and is closed-source. This conflicts directly with Framm's MIT license and open-source-first philosophy. macOS support is provided via OpenGL (deprecated but functional), or users may contribute a MoltenVK bridge to enable Vulkan on Apple silicon.

Installation

Get Framm in
under a minute.

CMake, vcpkg, Conan — pick your workflow. All dependencies vendor-pinned for reproducible builds.

CMakeLists.txt 
cmake_minimum_required(VERSION 3.20)
project(my_app LANGUAGES CXX)

include(FetchContent)
FetchContent_Declare(
  framm
  GIT_REPOSITORY https://github.com/GitAvaneesh/framm.git
  GIT_TAG        v0.2.0
)
FetchContent_MakeAvailable(framm)

add_executable(my_app main.cpp)
target_link_libraries(my_app PRIVATE framm::framm)
Build 
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
vcpkg.json 
{
  "name": "my-app",
  "version": "1.0.0",
  "dependencies": [
    "framm"
  ]
}
Terminal 
vcpkg install framm
cmake -B build -DCMAKE_TOOLCHAIN_FILE=$VCPKG_ROOT/scripts/buildsystems/vcpkg.cmake
cmake --build build
